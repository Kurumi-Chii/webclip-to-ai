连接你的 AI 智能体

把选中文字作为 JSON，POST 到你指定的接收接口

DeepSeek Harness 桌面版

将文字填入 Harness 当前会话的输入框，由你手动发送。

Harness 接收插件启动后，会在 Harness 主目录的 webclip-to-ai 文件夹生成 connection.json。此文件只在本机读取，不会上传到其他服务。

请先安装接收插件并导入配对文件。无需填写 DeepSeek 模型 API Key。配对文件包含本机连接凭据，请勿上传 GitHub。

接收地址

支持 HTTPS 与本地 HTTP 接口。这里需要接收 POST 请求的 API 地址，不能填写普通聊天网页地址。

配置仅保存在本机浏览器中，不会同步到其他设备。Token 只随请求发往接收接口。

请求内容

在 JSON 字符串值中使用 {{text}}（选中文字）、{{title}}（来源标题）、{{url}}（来源网址）。引号与换行会自动安全处理。删除 source 字段即可只发送文字。

自定义认证与请求头

例如 {"X-API-Key":"你的密钥"}。如果使用自定义 Authorization，请将上面的 Bearer Token 留空。

接入方式

默认发送 {"text":"选中的文字","source":{"title":"网页标题","url":"网页地址"}}。接收端将 text 写入智能体的会话、知识库或输入队列，即可在你的智能体中使用。

“发送测试文本”使用已保存配置，并会真正向接口提交一条测试消息。插件显示 HTTP 2xx 代表接口接收成功；是否写入你的智能体，由接收端处理。支持普通 JSON / 文本回复预览，不支持流式对话。

保存时只申请接收接口所在主机的访问权限。浏览器的权限以主机为范围，不限于单一路径或端口。插件不会自动读取所有网页。
