# 选文送 AI v1.3.0 · 本机框选识字候选版

浏览器扩展更新为 1.3.0；Harness 接收插件更新为 1.2.1，明确支持 dsh 0.2.1-rc.2 和 0.2.1-rc.5。rc.5 的实际 SDK / Host / HTTP 检查通过，原生桌面草稿确认仍待完成。[升级说明](DSH_RC5.zh-CN.md)。

- 新增 Alt + Shift + O 快捷键、面板按钮和右键框选入口。
- 本机识别简体中文 / 繁体中文 / 日文 / 英文，识别引擎和字库随包提供。
- 默认识别后交付到已连接的智能体；可取消自动交付，检查和编辑结果后再交付。Harness 消息仍由用户手动发送。
- 支持 Esc 取消、按实际截图比例裁剪、单任务和重复回调去重；切换页面、刷新或更改接收配置后停止自动交付并保留识别文字。
- 新增 offscreen 权限及本地 WebAssembly 的 CSP 支持，浏览器最低内核版本更新到 116。引擎和模型有独立第三方许可。

60 项自动化检查及四种语言的实际浏览器 Worker 样例通过。独立扩展测试浏览器启动受环境进程权限限制，**实际 Edge / Chrome 快捷键、原生截图、正式 offscreen 路由和 OCR 到 Harness 草稿的完整原生流程仍待手动验收**。这不是全兼容稳定版，尚未上传或触发 GitHub CI。

详见 [OCR 安装与验收说明](OCR.zh-CN.md)。识别结果可能有误，请在发送消息前检查。
