# 安装与升级

当前组件版本：**浏览器扩展 1.2.1、Harness 接收插件 1.2.0**。本次换行修正只更新浏览器扩展；已经启用的 Harness 1.2.0 不需要重新安装。

## 选择安装包

| 文件 | 用途 |
| --- | --- |
| `webclip-to-ai-v1.2.1.zip` | 完整安装包：浏览器扩展、Harness TGZ、说明 |
| `webclip-to-ai-extension-v1.2.1.zip` | 只安装浏览器扩展 |
| `harness-webclip-1.2.0.tgz` | 只安装 Harness 接收插件，不用解压 |
| `webclip-to-ai-source-v1.2.1.zip` | 源码与维护文件，可上传到自己的 GitHub 仓库 |

没有 Release 产物时，在源码目录运行 `npm run build`，上述文件会写入 `dist/`。浏览器扩展也可以直接加载源码中的 `extension/`，不需要构建。

## 一、安装浏览器扩展

1. 解压扩展 ZIP；如果使用完整安装包，进入其中的 `extension` 文件夹。
2. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`。
3. 开启 **开发者模式**，点击 **加载解压缩的扩展 / 加载已解压的扩展程序**。
4. 选择直接包含 `manifest.json` 的文件夹。
5. 在扩展详情中确认版本为 **1.2.1**，然后从浏览器拼图菜单固定 **选文送 AI**。

源码版的扩展文件夹叫 `extension`。旧的个人测试版可能叫 `text-to-agent`；不要将整个源码根目录或 ZIP 文件当作扩展目录。

## 二、选择接收方式

### A. DeepSeek Harness 当前输入框

本预览版要求 Harness 的 **dsh 运行时版本 0.2.1-rc.2**。Electron 版本或 Windows 文件属性里的版本不等于 dsh 运行时版本。若安装器明确提示不兼容，保留诊断并提交 Issue，不要强制跳过检查。

**安装接收插件：**

1. 在 Harness 左侧进入 **插件**。
2. 点 **添加插件**。如果使用旁边的下拉箭头，可选择 **安装第三方插件**。
3. 在 **插件包名** 输入框粘贴 `harness-webclip-1.2.0.tgz` 的本机完整路径，例如 `D:\Downloads\harness-webclip-1.2.0.tgz`。请替换成文件实际位置。
4. 按界面完成安装确认，点击 **安装**，完成后点 **立即启用**。
5. 如果提示需要重启，先完成现有任务，再从系统托盘退出并重新打开 Harness。

**导入本机配对文件：**

接收插件首次启动时会生成独立配对文件。默认位置：

| 系统 | 默认位置 |
| --- | --- |
| Windows | `%USERPROFILE%\.dsh\webclip-to-ai\connection.json` |
| macOS / Linux | `~/.dsh/webclip-to-ai/connection.json` |
| 设置了 `DSH_HOME` | `<DSH_HOME>/webclip-to-ai/connection.json` |

macOS / Linux 是路径规则说明，不代表本项目已经在这些系统完成 Harness 实测。接收插件会在启动日志中打印配对文件路径，**不会打印令牌**。

1. 打开浏览器 **选文送 AI → 接口设置**。
2. 在顶部 **DeepSeek Harness 桌面版** 区块选择 **导入本机配对文件**。
3. 选择刚生成的 `connection.json`。Windows 文件选择器中，可将上面的默认路径粘贴到文件名位置定位。
4. 点击 **保存 Harness 本地连接**，允许访问本机地址。
5. 在 Harness 打开目标普通会话，让输入框保持可编辑。
6. 返回浏览器，选中文字，右键 → **发送选中文字到 AI 智能体**。

浏览器显示 **已填入 DeepSeek Harness 当前会话输入框，请手动点击发送** 后，切回 Harness 检查草稿并发送。

不需要填写模型 API Key；配对文件在扩展内本地解析，不会上传到远程服务。它包含本机连接凭据，请勿提交到 GitHub 或发到公开 Issue。

### B. 自建智能体 HTTP 接口

1. 在扩展 **接口设置** 填写完整的 POST 接收地址。
2. 如有需要，填写 Bearer Token 或 JSON 格式的额外请求头。
3. 根据接收端字段修改 JSON 请求模板；至少保留一个字符串值中的 `{{text}}`。
4. 保存并授权接收主机。点击 **发送测试文本** 会真正提交测试请求。

模板支持嵌套对象与数组。占位符是 `{{text}}`、`{{title}}` 和 `{{url}}`，只替换字符串值，不执行脚本。删除 `source` 字段即可只交付文字。

HTTP 2xx 表示接口接收成功；接口还需要负责把文字写入你的智能体。普通聊天网页 URL、模型服务的基础地址或网页会员账号，不会自动提供这种接收能力。

## 三、网页无法选字时

打开扩展面板，点 **允许当前页选择与右键**，关闭面板后再用鼠标左键拖动选字。选好后在选区上按右键交付。点 **恢复网页原行为** 或刷新页面可撤销辅助功能。

这只针对常见选字限制。浏览器设置页、扩展商店、内置 PDF、部分跨域 iframe、图片和 canvas 不保证支持。

## 从旧版升级

关闭旧设置页。将新版扩展加载到稳定文件夹，或覆盖原先加载的扩展文件后，在扩展管理页点 **重新加载**。再次打开设置，确认 **1.2.1** 以及配对文件导入入口。

只保留一个启用的「选文送 AI」，避免重复右键菜单。旧版安装包中的固定配对方式不再用于公开版；请更新 Harness 接收插件并导入运行时生成的新文件。更新接收包前，在 Harness 停用旧接收包，避免本机端口被重复占用。

## 停用与删除

在浏览器扩展管理页停用或移除扩展；在 Harness 插件页停用或卸载接收包。接收包停用后会关闭本地端口。是否保留本机配对文件由你决定；它不包含模型密钥或会话历史。
