# 选文送 AI v1.2.1 · 换行修正预览版

**浏览器扩展 1.2.1；Harness 接收插件继续使用 1.2.0。** 已安装接收插件的用户只需在浏览器扩展管理页重新加载新版扩展，无需重新配对或重装 Harness 接收插件。

## 修正

在用户协助的 Edge 验收中，发现网页两行选文写入后被合并成一行。此版本在显式右键交付时读取被点击框架的选区原文，与原生菜单选文核对一致后保留其换行。受保护页面读取失败时仍使用原生菜单文字作为回退。

新增回归检查：多行原文通过 HTTP 完整交付、只读取被点击框架、页面改变选区时不替换原有词句、框架不可读时可靠回退。

## 验证状态

38 项自动化检查、11 项实际后台接入检查已通过。用户协助的 Edge 真实验收已确认右键交付、多行修正、旧草稿保留、一次撤销、不自动发送，以及选字辅助的重复启用、恢复、重新开启和刷新行为。

Chrome、完整浏览器重启后的配对保持和部分真实界面竞争场景仍待验证；GitHub Actions 尚未在已发布仓库运行。当前适合作为 Edge + Harness 核心功能已验收的 **Pre-release**，不声明全平台稳定。
